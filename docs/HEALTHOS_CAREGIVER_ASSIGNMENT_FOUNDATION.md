# HealthOS Caregiver Assignment Foundation

## Model

`caregiver_assignments` represents limited access from a caregiver to a subject care profile.

## Limited Access Rules

- Caregiver assignment is not full medical access.
- Schedule access defaults to true.
- Records and medication summary access default to false.
- Notes default to false.
- Explicit sharing permissions are still required for records and medication.

## Deferred

- Caregiver billing.
- Caregiver rates.
- Payments.
- Full caregiver dashboard backend.
- Profile-switcher caregiver mode.

## UI Rule

Caregiver identity is not added to the bottom nav or default profile switcher by this batch.
