# HealthOS Exercise + Food Database Deferred Plan

Batch 9 does not import a full exercise database or food database.

## Exercise Database Deferred

Future work should define:

- Source licensing.
- Exercise catalog schema.
- Muscle group taxonomy.
- Equipment taxonomy.
- Review and moderation workflow.
- Import validation.

## Food Database Deferred

Future work should define:

- Trusted provider and license model.
- Barcode lookup storage rules.
- Nutrient source confidence.
- Allergen warning limitations.
- User review flow.

## Current Batch Behavior

Exercise names, food names, nutrients, and muscle tags remain user-entered or reviewed metadata. The system does not claim medical or nutritional correctness.
