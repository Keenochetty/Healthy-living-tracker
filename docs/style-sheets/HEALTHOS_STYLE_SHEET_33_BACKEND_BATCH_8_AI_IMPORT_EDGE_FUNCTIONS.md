# HealthOS Style Sheet 33 - Backend Batch 8: AI Import Review Persistence + Edge Function Hardening

Source sheet captured from the Batch 8 request. Backend Batch 8 is limited to AI extraction job metadata, review-first import envelopes, review events, source evidence metadata, Edge Function validation, server-only AI secret handling, and safe client service/hooks. It must not deploy functions, run remote Supabase commands, expose secrets in the Expo client, create fake AI output, or auto-save AI output into final realm tables.
