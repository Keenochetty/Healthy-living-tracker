# HealthOS Style Sheet 13 - Baby / Child Realm

## Purpose

Baby / Child is a parent-controlled care realm for profiles, today care summary, feeding, sleep, diapers, growth, vaccines, milestones, solids, medication and symptoms, caregiver notes, records, family sharing, pregnancy connection, trusted content, and safe AI support.

## Rules

- Baby/Child is not added to the visible bottom nav.
- Parent/guardian controls baby and young child profiles.
- Do not invent child profiles, names, ages, logs, vaccines, growth values, milestones, caregiver notes, records, or article links.
- Do not hardcode vaccine schedules.
- Do not calculate growth percentiles without source-backed standards.
- Do not diagnose symptoms or recommend medication doses.
- Do not auto-share child data.

## Verification

Run typecheck only:

```bash
npm run typecheck
```
