# HealthOS Style Sheet 26 - Backend Batch 1: Account, Profile, Onboarding + Preferences

## Purpose

Implement the account-level backend foundation for profiles, onboarding preferences, app preferences, notification preference storage, profile photo metadata, owner-only RLS draft, and typed frontend service/hook contracts.

## Rules

- Do not redesign UI.
- Do not touch unrelated realm schemas.
- Do not run remote Supabase commands.
- Do not apply migrations.
- Do not add fake seed data.
- Do not install packages.
- Run typecheck only.
