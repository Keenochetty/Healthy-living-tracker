# POPIA Preparation Checklist

Prepared for legal review. Do not claim legal compliance automatically.

Source checked: Information Regulator South Africa POPIA guidance, https://inforegulator.org.za/popia/

## Processing Purpose
- Define lawful purpose for each data category.
- Record consent for health and special personal information processing.
- Explain health-data use in plain language.

## Special Personal Information
- Treat health, biometric, pregnancy, contraception, child, medication, records, and family data as sensitive.
- Default sensitive modules to private.
- Minimize data collection to user-selected modules.

## Data Subject Rights Preparation
- Access/export request flow.
- Correction/update flow through profile and realm forms.
- Deletion request flow.
- Consent withdrawal flow.
- Sharing revoke flow.

## Children And Family
- Parent/guardian-managed child profiles.
- Teen transition review.
- Adult conversion blocks parent access by default unless newly granted.
- Caregiver access limited to explicit task permissions.

## Security Safeguards
- Local-first storage.
- RLS-ready cloud schema documentation.
- Private records/documents by default.
- Audit logs for sensitive actions.
- Breach response placeholder required before release.

## Operational Readiness
- Information officer/contact placeholder.
- Third-party processor register.
- Cross-border transfer review.
- Privacy policy availability.
- App-store disclosure review.
